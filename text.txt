Clase 1 - Ordenación básica: Insertion Sort

* Recorre la lista e "inserta" cada elemento en su posición correcta dentro
* de la parte ya ordenada.
* Es intuitivo y muy útil en listas pequeñas o casi ordenadas.
*
* COMPLEJIDAD:
*
* - Mejor caso: O(n)
* - Peor caso: O(n^2)
* - In-place (no usa memoria extra)

* PSEUDOCÓDIGO:
	procedure insertionSort(A)
		for i ← 1 to length(A) - 1 do
			key ← A[i]
			j ← i - 1

			while j ≥ 0 and A[j] > key do
				A[j + 1] ← A[j]
				j ← j - 1
			end while

			A[j + 1] ← key
		end for
	end procedure

Clase 2 - Divide y vencerás: Merge Sort

* Divide el array en dos mitades, ordena cada mitad recursivamente y luego
* las combina ("merge")
*
* VENTAJAS:
* - Complejidad: O(log n) en todos los casos
* - Muy estable
* - Determinístico
* DESVENTAJA: Usa memoria extra (no es in-place)

* PSEUDOCÓDIGO:
	procedure mergeSort(A)
		if length(A) > 1 then
			mid ← length(A) / 2
			left ← A[0..mid-1]
			right ← A[mid..end]

			mergeSort(left)
			mergeSort(right)

			merge(left, right, A)
		end if
	end procedure

	procedure merge(left, right, A)
		i ← 0
		j ← 0
		k ← 0

		while i < length(left) and j < length(right) do
			if left[i] ≤ right[j] then
				A[k] ← left[i]
				i ← i + 1
			else
				A[k] ← right[j]
				j ← j + 1
			end if
			k ← k + 1
		end while

		while i < length(left) do
			A[k] ← left[i]
			i ← i + 1
			k ← k + 1
		end while

		while j < length(right) do
			A[k] ← right[j]
			j ← j + 1
			k ← k + 1
		end while
	end procedure
