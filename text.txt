Clase 1 - Ordenación básica: Insertion Sort

* Recorre la lista e "inserta" cada elemento en su posición correcta dentro
* de la parte ya ordenada.
* Es intuitivo y muy útil en listas pequeñas o casi ordenadas.
*
* COMPLEJIDAD:
*
* - Mejor caso: O(n)
* - Peor caso: O(n^2)
* - In-place (no usa memoria extra)

* PSEUDOCÓDIGO:
	procedure insertionSort(A)
		for i ← 1 to length(A) - 1 do
			key ← A[i]
			j ← i - 1

			while j ≥ 0 and A[j] > key do
				A[j + 1] ← A[j]
				j ← j - 1
			end while

			A[j + 1] ← key
		end for
	end procedure

Clase 2 - Divide y vencerás: Merge Sort

* Divide el array en dos mitades, ordena cada mitad recursivamente y luego
* las combina ("merge")
*
* VENTAJAS:
* - Complejidad: O(log n) en todos los casos
* - Muy estable
* - Determinístico
* DESVENTAJA: Usa memoria extra (no es in-place)

* PSEUDOCÓDIGO:
	procedure mergeSort(A)
		if length(A) > 1 then
			mid ← length(A) / 2
			left ← A[0..mid-1]
			right ← A[mid..end]

			mergeSort(left)
			mergeSort(right)

			merge(left, right, A)
		end if
	end procedure

	procedure merge(left, right, A)
		i ← 0
		j ← 0
		k ← 0

		while i < length(left) and j < length(right) do
			if left[i] ≤ right[j] then
				A[k] ← left[i]
				i ← i + 1
			else
				A[k] ← right[j]
				j ← j + 1
			end if
			k ← k + 1
		end while

		while i < length(left) do
			A[k] ← left[i]
			i ← i + 1
			k ← k + 1
		end while

		while j < length(right) do
			A[k] ← right[j]
			j ← j + 1
			k ← k + 1
		end while
	end procedure

Clase 3 - QuickSort (ordenación rápida)

* Es uno de los algoritmos más usados por su velocidad promedio. Se basa en
* divide y vencerás.
* 1. Se elige un pivote
* 2. Se particiona el array: todos los elementos < pivot a un lado, los ≥ pivot al otro
* 3. Se ordenan recursivamente ambas partes
*
* COMPLEJIDADES:
* - Promedio: O(n log n)
* - Peor caso (si el pivot es pésimo): O(n^2)
* - Muy rápido en práctica
* - In-place
* - No estable

* PSEUDOCÓDIGO
	procedure quickSort(A, low, high)
		if low < high then
			p ← partition(A, low, high)
			quickSort(A, low, p - 1)
			quickSort(A, p + 1, high)
		end if
	end procedure

	procedure partition(A, low, high)
		pivot ← A[high]
		i ← low - 1

		for j ← low to high - 1 do
			if A[j] ≤ pivot then
				i ← i + 1
				swap(A[i], A[j])
			end if
		end for

		swap(A[i + 1], A[high])
		return i + 1
	end procedure
